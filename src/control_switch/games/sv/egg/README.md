# 孵蛋刷闪 `sv/egg`

流程照 PokemonAutomation（Arduino-Source）的 `EggAutonomous`（零区闸口）：开野餐、做三明治、从篮子收蛋、换成孵蛋队伍、骑坐骑绕圈孵、逐只检查，一盒孵完重启游戏回档或放生整盒。只用取图和按键，不读内存。

启动时指定机器：`make start script=sv/egg switch=lite`。

## 游戏里要先准备好

- 人站在零区闸口（飞行点）旁边的空地，没有骑坐骑。
- 设置：语速快、给昵称关、跳过学习招式开、镜头辅助开。
- 包里有超级花生酱三明治（食谱 17）的材料：香蕉、花生酱、黄油，食谱已经解锁。
- 野餐队伍：第 1 只是亲代，另一只是百变怪；亲代是队伍里第一只不是百变怪的。队伍没满也行，篮子里的蛋直接进盒子（真机上验过）。
- 盒子：相邻的三个盒子，开始时盒子停在这三个里任何一个都行，程序从开着的盒子往前找放亲代和带队宝可梦的那个（下面按盒子 2 写）：
  - 盒子 2 第 1 格放孵蛋时带队的宝可梦（特性是火焰之躯）；这个盒子第 1 列其余的格子、第 2 列空着，换队伍时野餐队伍放在这里。
  - 盒子 3（后面一个）全空，收到的蛋放在这里。
  - 盒子 4（再后面一个）空着，闪光放在这里，满了就结束。
- 评定功能没解锁时读不到「最棒」的项数，不换亲代，日志里记一条。

## 步骤

| 步骤 | 做什么 |
|---|---|
| initialize | 换新日志文件，退回野外，打开盒子看队伍，找到放亲代和带队的盒子，读亲代（名字、「最棒」项数），数放蛋的盒子和队伍里的蛋：有蛋返回 hatch；没有蛋、队伍超过两只返回 release（放生）；没有蛋、队伍是亲代和百变怪返回 fetch。存档 |
| fetch | 开野餐、做三明治、走到篮子前反复查篮子（间隔 180 秒，快收满时按比例缩短，最少 30 秒，最多 30 分钟，收满 30 个停）、收野餐、飞回闸口、换成孵蛋队伍 |
| hatch | 一列一批：下坡、绕圈孵、飞回闸口、开盒子逐只检查、装下一列。整盒孵完：没留下东西就重启游戏回档，留过就放生整盒、换回野餐队伍、存档 |

留不留：闪光放进右边盒子的空格并推送（带截图），存档，继续刷，右边盒子满了就结束；和亲代同种、「最棒」项数比亲代多的和亲代交换，存档；其余不留，放回盒子，不当场放生。

一盒一次存档：开始存一次，留下东西之后孵下一批之前存一次，放生整盒、换回野餐队伍之后存一次。一盒什么都没留下就不存，重启游戏回到开始的存档。

出错直接抛异常，入口会推送通知并停下，没有上游那样的出错重启重试。不识别野生宝可梦的攻击。

## 和上游不一样的地方

- 手：上游用自己的模板，这里的模板图（`../data/sandwich_hand_free.png`、`sandwich_hand_grabbing.png`）是从真机 720p 截图裁的，找白色连通区域再比形状。
- 光标：上游用渐变箭头的位置，这里用箭头黄绿色那一段的位置，格子本身的黄色会闪，不能用。
- 盘子标签变黄的检查放在移动手之外：抓着香蕉移到目标框时看标签是不是黄色，不是就当盘子空了。
- 开野餐、存档、收野餐（`games/sv/actions/`）改成看画面：认到什么状态按什么键，没反应再按。
- 找手的最小面积：空手 4000、抓着 3600（1080p 的像素数，上游 5000、4500），再加形状误差 `hand_tolerance` 0.15、`hand_max_mismatch` 0.1；模板是真机 720p 截图，上游的阈值在这里认不全。
- 做三明治前不读盘子标签的文字（上游用 OCR 认材料）：只有香蕉一种，直接当成中间那个盘子。
- 飞回闸口（`fly.py`）：在地图截图里找飞行点图标，把光标推过去（上游是摇杆往下轻推 0.252、推 160 毫秒，再飞）。
- 等篮子时每 30 秒按一下 L 防 Switch 休眠（上游没有）。
- 吃完三明治认到野餐后，等一会儿再看一次才算（真机上吃的过程中出现过误认）。
- 放生：靠操作菜单选中行的行号找「放生」（上游是按 UP、UP 盲按），放完检查格子空了没有。
- 重启回档之后看画面等回到野外，不固定等。
- 光标认黄绿色箭头那一段，色相下限比别处高一点（1080p 采集卡上格子的黄色会和箭头连在一起）。

## 配置

`config.py`：走路路线（`picnic_route`、`basket_route`、`ramp_route`）、查篮子间隔、识别用的区域和颜色。坐标都是占画面宽高的比例，720p 和 1080p 通用。
