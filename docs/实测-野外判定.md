# 实测：朱紫认野外画面（is_overworld）

代码在 `src/control_switch/games/sv/verify.py` 的 `is_overworld`。

## 方法

- 样本：`runs/logs/sv-egg/failed` 下孵蛋脚本出错时存下的 3857 张截图（1280×720），包括野外、主菜单、盒子、地图、野餐、做三明治、飞行动画、放生确认等画面。
- 渐亮过程用的是 `20261126-101414` 这一次飞到零区闸口的连续截图 2124 到 2132。
- 测量脚本不在项目里，保存在会话的临时目录。

## 判定方法

小地图跟着镜头转，所以：

- 圆心表示人位置的黄色圆点位置固定，直接看圆心一小块（720p 下 (1160, 598) 上下左右 6 像素）的黄色占比。
- 外圈分青、绿、黄、红四段，色段跟着镜头转，位置不固定。只在外圈的细边上取两圈点（半径是画面高度的 0.124 和 0.128），看每种颜色各占多少，不看在哪。
- N 标记沿着外圈移动，不用。圈里面的地图内容一直在变，也不用。

两个条件都满足才算野外：圆点黄色占比超过 0.8，外圈四种颜色各占至少 10%。

## 结果

### 飞到闸口落地时画面从黑慢慢变亮

| 帧 | 画面 | 圆点亮度中位数 | 外圈亮度中位数（青 / 绿 / 黄 / 红） |
|---|---|---|---|
| 2124 到 2126 | 飞行动画 | 没有圆点 | 没有外圈 |
| 2127 | 黑屏后开始变亮 | 58 | 54 / 57 / 57 / 57 |
| 2128 | | 119 | 110 / 117 / 116 / 120 |
| 2129 | | 144 | 132 / 142 / 141 / 143 |
| 2130 | | 185 | 173 / 183 / 183 / 185 |
| 2131 | 已经开始开盒子 | 212 | 199 / 209 / 208 / 210 |
| 2132 | | 237 | 223 / 235 / 233 / 236 |
| 完全亮起来（330 张） | 野外 | 252 到 255 | 225 / 248 / 249 / 243 |

- 改之前只看外圈三种颜色、亮度下限 150，2130 就判成了野外，脚本马上去开盒子，这时画面还没亮完、人还不能动。之前飞到闸口后按 PLUS 没骑上坐骑，很可能就是这个原因。
- 所有能看到圆点的截图里，95% 以上的圆点亮度是 252 到 255，就是画面完全亮起来的值。

### 完全亮起来时外圈四种颜色

| 颜色 | H | S | 亮度中位数 |
|---|---|---|---|
| 青 | 85 到 105 | 103 以上 | 225 |
| 绿 | 66 到 75 | 155 以上 | 248 |
| 黄 | 26 到 35 | 89 到 181 | 249 |
| 红 | 0 到 8，或 170 以上 | 87 到 242 | 243 |

红色的 H 跨在 0 和 180 两头，代码里分两段范围。黄和红的饱和度比青、绿低，红色的饱和度下限用 80。

## 结论

- 圆点亮度下限用 245：画面没亮完就不算野外，2127 到 2132 都判成不是野外。
- 外圈亮度下限保持 150：外圈和圆点一起变亮，但完全亮起来时青色也只有 225，用外圈判断画面亮没亮完不如圆点准，这件事交给圆点。
- 圆点通过的截图里，外圈四种颜色每种都超过 10%，没有一张被外圈的条件挡下来。

## 没测到的

- 只有 720p（botbase）的截图，没有 1080p 采集卡的截图。
- 渐亮过程只测了飞行落地这一次，读档、重启后回到野外的渐亮没有单独测。
- 夜里、下雨、洞窟里圆点和外圈的亮度没有测，下限 245 在这些情况下会不会太高还不知道。
