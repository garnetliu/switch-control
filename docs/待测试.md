# 已通过

分组和上面一样。每条写的是：测的是什么，怎么通过的。

## 战斗（`src/shiny_steps/battle.py`）

- 一进 `battle()` 就读队伍内存：path 认到「出现了」后马上进 battle，这时战斗菜单还没出来，要确认这时内存已经能读到。
  - 怎么通过的：11-10 实测，22 场开头都读到了，没有报错；读到的队伍和这一局抓到的对得上。
- 读队伍内存后更新队伍：位置上的宝可梦变了的按满血算，没变的沿用原血量。
  - 怎么通过的：11-10 实测，队友带走新宝可梦后，下一场开始时日志里的队伍位置对得上，首领战也对。

  - 怎么通过的：11-10 实测，自己极巨化后和队友极巨化的 3 回合里都判断为 False，没有误按。

  - 怎么通过的：11-10 实测，第 4 回合日志里招式名字换回了普通招式。
