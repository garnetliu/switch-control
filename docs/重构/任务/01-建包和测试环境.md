# 任务 01：建包和测试环境

## 目标

建一个空的包 `control_switch`，让它能被安装和引用；配好 pytest 和 pyright。现有代码一行不动，`make start` 照常能跑。

## 开始前的状态

- 代码都在 `src/` 下的 `libs`、`tools`、`type`、`sv`、`swsh` 五个目录和 `main.py`、`restart.py`、`scripts.py` 里，靠 `python src/main.py` 运行。
- `pyproject.toml` 里没有 `[build-system]`，dev 依赖只有 ruff。
- 没有 `tests/`。
- 工作区是干净的：`git status --short` 没有输出。不干净时先停下来问，不要开始。

## 约定

- 包名 `control_switch`，位置 `src/control_switch/`。
- 构建用 hatchling。
- 测试放在仓库根目录的 `tests/`，pytest 用 `importlib` 导入方式，这样不同目录下可以有同名的测试文件，`tests/` 里不放 `__init__.py`。
- 类型检查用 pyright 的标准模式（`standard`），不用严格模式（`strict`）。

## 写测试

只能改 `tests/`。

新建 `tests/test_package.py`：

- `import control_switch` 能成功。
- `control_switch.__file__` 在仓库的 `src/control_switch/` 下。

## 实现

不能改 `tests/`。

1. 新建 `src/control_switch/__init__.py`，只写一行说明这个包是什么的文档字符串。
2. `pyproject.toml`：
   - 加 `[build-system]`，用 hatchling。
   - 加 `[tool.hatch.build.targets.wheel]`，`packages = ["src/control_switch"]`。
   - dev 依赖加 `pytest`、`pytest-cov`、`pyright`。
   - 加 `[tool.pytest.ini_options]`：`testpaths = ["tests"]`，`addopts = "--import-mode=importlib"`。
   - 加 `[tool.pyright]`：`include = ["src/control_switch", "tests"]`，`pythonVersion = "3.11"`，`typeCheckingMode = "standard"`。
3. `Makefile` 加三个命令，并写进 `.PHONY`：
   - `test`：`uv run pytest`
   - `typecheck`：`uv run pyright`
   - `coverage`：`uv run pytest --cov=control_switch --cov-report=term-missing`
4. 运行 `uv sync`，`uv.lock` 会跟着更新。
5. `.gitignore` 加一行 `.coverage`，这是 `make coverage` 生成的数据文件。
6. `README.md` 的「命令」表在 `make lint` 那一行后面加三行：
   - `make test`：跑测试
   - `make typecheck`：类型检查
   - `make coverage`：跑测试并打印覆盖率

不要动 `src/` 下现有的任何文件，不要动 `start`、`restart`、`find` 这几个命令。

## 测试

下面是至少要过的检查，逐条写出结果。这些之外还要按用户的用法自己找问题。自己找问题时，不运行 `make start`、`make restart`、`uv run python src/main.py`、`uv run python src/restart.py`，它们会连接 Switch；也不运行 `make find`，它会改写 `.env`。这一节里明确写出的命令除外。需要连着 Switch 才能确认的，在结果里列出来，交给人在真机上确认。

1. `uv sync` 成功。
2. `make test` 全部通过。
3. `make lint` 没有新增的报错。`make coverage` 能跑完并打印出覆盖率。
4. `make typecheck` 0 报错。
5. `git status --short -uall` 里改动的只有：`.gitignore`、`README.md`、`pyproject.toml`、`uv.lock`、`Makefile`、`src/control_switch/__init__.py`、`tests/test_package.py`。
6. `uv run python -c "import sys; sys.path.insert(0, 'src'); import scripts; scripts.load_script('sv/outbreak')"` 不报错，说明原来的代码还能被引用。

## 要在真机上确认的

- `make start` 能正常开始跑。
