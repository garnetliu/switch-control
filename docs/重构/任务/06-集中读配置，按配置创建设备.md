# 任务 06：集中读配置，按配置创建设备

## 目标

读环境变量的地方集中到 `settings.py` 一个文件；新增 `SCREEN`、`CONTROLLER`、`MEMORY` 三项配置，由 `device/factory.py` 按配置创建设备。这次只有 botbase 一种实现，三项都不写时和现在的行为完全一样。

## 开始前的状态

- 读环境变量的地方分散在：
  - `device/botbase.py` 的 `connect_botbase`：`SWITCH_CONNECTION`（不写是 `wifi`）、`SWITCH_IP`、`SWITCH_PORT`
  - `notifier.py`：`DISCORD_WEBHOOK_URL`
  - `pkhex.py`：`PKHEX_API_URL`（`Pkhex` 的构造参数 `api_url` 没传时读）
  - `games/swsh/lair/game_state.py`：`KEEP_PATH`（等于 `"1"` 才算开）
- `__main__.py` 里先 `load_dotenv()`，再 `connect_botbase()`，再 `script.SESSION(botbase, botbase, botbase)`。
- `scripts/find_switch.py` 自己读 `SWITCH_MAC`，它是单独运行的，这次不动。

## 约定

### `settings.py`

- `Settings`：不可变的 dataclass。

| 字段 | 环境变量 | 不写时 | 可以写的值 |
|---|---|---|---|
| `screen` | `SCREEN` | `"botbase"` | `botbase`、`capture` |
| `controller` | `CONTROLLER` | `"botbase"` | `botbase`、`serial` |
| `memory` | `MEMORY` | `"botbase"` | `botbase`、`none` |
| `switch_connection` | `SWITCH_CONNECTION` | `"wifi"` | `wifi`、`usb` |
| `switch_ip` | `SWITCH_IP` | `None` | |
| `switch_port` | `SWITCH_PORT` | `None` | 整数 |
| `pkhex_api_url` | `PKHEX_API_URL` | `None` | |
| `discord_webhook_url` | `DISCORD_WEBHOOK_URL` | `None` | |
| `keep_path` | `KEEP_PATH` | `False` | 等于 `"1"` 才是 `True` |

- `load_settings(env=os.environ) -> Settings`：有可选值的几项不分大小写，值不认识时抛 `ValueError`，报错里写明是哪一项、写了什么、可以写什么。`SWITCH_PORT` 不是整数时同样报错。空字符串当作没写。
- `settings.py` 之外，`src/control_switch/` 里不再读环境变量。

### `device/factory.py`

- `Devices`：`NamedTuple`，三个字段 `screen`、`controller`、`memory`，`memory` 可以是 `None`。
- `create_devices(settings) -> Devices`：
  - 三项里选了 `botbase` 的共用同一个 `Botbase`，只连接一次。
  - 三项都没选 `botbase` 时不去连接。
  - `MEMORY=none` 时 `memory` 是 `None`。
  - `capture`、`serial` 这次还没有实现，抛 `NotImplementedError`，报错里写明是哪一项。
- `connect_botbase` 改成接收 `settings`：`connect_botbase(settings)`。WiFi 连接但没有 ip 或端口时抛 `ValueError`，说明缺哪一项。
- `device/__init__.py` 多导出 `Devices`、`create_devices`。

### 其他地方怎么拿到配置

- `Session(config, settings, devices)`：`settings` 挂在 `sw.settings` 上；`Notifier` 创建时传 `settings.discord_webhook_url`。
- 脚本的 `SESSION(settings, devices)`。
- `LairSession` 里创建 `Pkhex` 时传 `settings.pkhex_api_url`，`OutbreakSession` 同样。`Pkhex` 里没传地址时用默认地址，不再读环境变量。
- `GameState` 需要的 `KEEP_PATH` 由 `LairSession` 创建它时传进去。

### 入口

`load_dotenv()` → `settings = load_settings()` → `devices = create_devices(settings)` → `sw = script.SESSION(settings, devices)`。
