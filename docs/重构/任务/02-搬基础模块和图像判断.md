   - `read_line`、`text_lines`、`find_options`：用 `路线上的界面-要走哪条路.jpg` 的对话框，区域的数值直接写在测试里，结果和旧代码一样；`text_lines` 返回的区域是整张图上的比例坐标，从上到下排列。

   - `brightness`、`color_ratio`、`has_color`、`edge_ratio`：用自己生成的图（编码成 png 再传进去）。全白的图亮度是 255，`edge_ratio` 是 0；左半红、右半白的图，红色的 `color_ratio` 是 0.5；`has_color` 在占比正好等于 `min_ratio` 时是 False。

   - `match_template`、`match_template_position`、`has_template`：从截图里裁一块当模板，在包含它的区域里匹配度接近 1，返回的位置是模板左上角相对区域的像素位置；区域比模板小时返回 0 和 `(0, 0)`；给了 `lower`、`upper` 时区域按颜色转成黑白图再匹配，模板也用同样处理过的单通道图。`has_template` 用同一个模板，`min_score` 比匹配度低、比匹配度高各一条。
   - `match_sprite`：把截图的一大块裁出来当模板，区域取这一块里面的一小块时接近 1；区域比模板大时返回 0。
