# 任务 02：搬基础模块和图像判断

## 目标

把不依赖连接的模块搬进 `control_switch` 包：类型、配置、通知、PKHeX 客户端、图像判断、文字比较。只移动文件和改 import，逻辑一行不动。

## 开始前的状态

- `src/control_switch/` 是空包，pytest 能跑。
- 要搬的文件都不引用 `Switch`：
  - `src/type/type.py`：`Rect`、`Hsv`
  - `src/libs/config.py`：`ROOT`、`BaseConfig`、`BaseRects`，引用了 `type`
  - `src/libs/notifier.py`：`Notifier`
  - `src/libs/pkhex.py`：`Pkhex`
  - `src/libs/check_image.py`：`ImageChecker`，引用了 `type`
  - `src/tools/text.py`：`contains`、`similarity`、`levenshtein`

## 约定

文件对照：

| 原来 | 搬到 |
|---|---|
| `src/type/type.py` | `src/control_switch/types.py` |
| `src/libs/config.py` | `src/control_switch/config.py` |
| `src/libs/notifier.py` | `src/control_switch/notifier.py` |
| `src/libs/pkhex.py` | `src/control_switch/pkhex.py` |
| `src/libs/check_image.py` | `src/control_switch/vision/image.py` |
| `src/tools/text.py` | `src/control_switch/vision/text.py` |

引用的写法：

| 原来 | 改成 |
|---|---|
| `from type import Rect, Hsv` | `from control_switch.types import Rect, Hsv` |
| `from libs.config import ...`、`from libs import BaseConfig, BaseRects` | `from control_switch.config import ...` |
| `from libs import Notifier` | `from control_switch.notifier import Notifier` |
| `from libs import Pkhex` | `from control_switch.pkhex import Pkhex` |
| `from libs import ImageChecker` | `from control_switch.vision import ImageChecker` |
| `from tools.text import ...` | `from control_switch.vision.text import ...` |

- `src/control_switch/vision/__init__.py` 导出 `ImageChecker`。
- `config.py` 里的 `ROOT` 搬完后仍然要指向仓库根目录。
- `Switch` 这次不搬，还留在 `src/libs/switch.py`，`from libs import Switch` 继续能用。

## 写测试

只能改 `tests/`。期望值用搬之前的代码跑出来的结果（设置 `PYTHONPATH=src` 后引用 `libs.check_image`、`tools.text`），不要自己推算。

测试图片从 `logs/keep/` 里挑需要的复制到 `tests/images/`。`logs/` 不进版本库，所以要复制，不能直接引用。

1. `tests/vision/test_text.py`
   - `levenshtein`：相同的字符串、差一个字、空字符串。
   - `contains`：完全包含、错一个字仍然算包含、完全无关、带空白和标点。
   - `similarity`：相同是 1，完全不同是 0。
2. `tests/vision/test_image.py`
   - 传入不是图片的字节，抛 `ValueError`。
   - `crop` 按比例裁出来的大小对。
   - `has_text`：用 `路线上的界面-要走哪条路.jpg`，在对话框那一行能找到「要走哪条路」，找不到一句无关的话。区域的数值直接写在测试里。
   - `read_text`：空的区域返回空字符串。
   - `is_black`：自己生成一张全黑的图是 True，真机截图是 False。
   - `save`：原图是 jpg、存成 `.jpg` 时，写出的文件和原始字节完全一样。
3. `tests/test_config.py`
   - `ROOT / "pyproject.toml"` 存在。

## 实现

不能改 `tests/`。

1. 按「文件对照」用 `git mv` 移动 6 个文件，新建 `src/control_switch/vision/__init__.py`。
2. 删掉 `src/type/` 整个目录。
3. `src/libs/__init__.py` 只保留 `Switch` 的导出。
4. `src/tools/__init__.py` 不变（它没有导出 `text` 里的东西）。
5. 全项目按「引用的写法」改 import，包括被搬的文件自己、`src/libs/switch.py`、`src/tools/`、`src/sv/`、`src/swsh/`。一行里同时引用了 `Switch` 和别的名字的，拆成两行。
6. 跑 `make typecheck`，把搬进来的文件里的报错清掉。为了消除 pyright 报错可以补类型标注、加必要的判空，但不能改变运行时的行为。
7. 除了 import 和上一条，不改任何代码。
