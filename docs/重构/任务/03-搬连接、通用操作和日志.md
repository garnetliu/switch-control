# 任务 03：搬连接、通用操作和日志

## 目标

把连接、等画面、菜单、重启、日志搬进 `control_switch` 包，把找 Switch 的脚本搬到 `scripts/`。只移动文件和改 import，逻辑一行不动。`Switch` 类这次不拆，原样搬过去。

## 开始前的状态

- `control_switch` 里已经有 `types`、`config`、`notifier`、`pkhex`、`vision`。
- 还在外面的：
  - `src/libs/switch.py`：`Switch`、`Frame`，以及 WiFi 和 USB 两种连接
  - `src/tools/wait.py`：`capture`、`save_frames`、`wait_for`、`press_until`、`act_until`
  - `src/tools/menu_last_item.py`、`src/tools/move_menu_option.py`
  - `src/tools/restart.py`：`restart`、`restart_to_title`、`enter_game`
  - `src/tools/log.py`：`init_log`、`new_log`
  - `src/tools/find_switch.py`：用系统 Python 单独运行，往 `.env` 写 ip，不引用项目里的其他代码

## 写测试

只能改 `tests/`。

在 `tests/conftest.py` 里做一个假的连接，给下面的测试用。它不继承 `Switch`，只要有这些东西：

- `pixel_peek()`：按顺序返回事先给定的图片字节，用完后一直返回最后一张。图片用 `tests/images/` 里的 jpg。
- `click(button, delay)`：把按过的键记在一个列表里，不等待。
- `config`：`interval` 是 0，`timeout` 很短，`failed_dir` 指向 pytest 的临时目录。
- `frames`：空列表。`step`：一个字符串。
- `title_id()`：返回事先给定的值，重启的测试要用。`config` 上重启用到的几项（`rects`、`game_title_ids`、`load_timeout`、`boot_timeout`、彩色画面的三项）直接用 `BaseConfig` 的，超时改短。

`tests/flow/test_wait.py`：

- `capture`：返回的图能用，`frames` 里多了一条，带着当时的 `step` 和传进去的说明。
- `wait_for`：条件第一次就满足时立刻返回；第 3 张图才满足时返回的是第 3 张；一直不满足抛 `TimeoutError`，报错里有传进去的说明。
- `press_until`：条件一开始就满足时一次都不按；不满足时按的是指定的键。
- `act_until`：动作至少做了一次之后条件满足，返回；一直不满足抛 `TimeoutError`。
- `save_frames`：写出的文件数和 `frames` 一样，文件名是「序号-时分秒-步骤-说明.jpg」，说明里的 `/` 换成了 `_`。

`tests/test_log.py`：

- `new_log` 在 `config.log_dir/名字/` 下建出一个 `.log` 文件。测试结束时把加到根 logger 上的 handler 清掉，不影响别的测试。

`tests/flow/test_menu.py`，图片从 `logs/swsh-lair/failed/` 里挑带菜单的截图（文件名里有「传说菜单」「开场白的菜单」「大厅菜单的光标移一格」）复制到 `tests/images/`，期望值用搬之前的代码跑出来的结果：

- `menu_last_item`：有菜单的图返回最后一项的文字；指定序号时返回那一项；没有菜单的图返回空字符串；传了对话区域而那里没有文字时返回空字符串。
- `move_menu_option`：目标是序号、目标是文字各一条，光标已经在目标上时不移动；目标文字差一个字也能对上；图里没有菜单时抛 `RuntimeError`。

`tests/flow/test_restart.py`，没有 HOME 菜单和选用户界面的截图，把 `ImageChecker` 上用到的判断（`has_text`、`is_black`、`color_ratio`）换成按事先给定的顺序返回结果：

- `restart_to_title`：一开始不在 HOME 时先按 HOME；一开始就在 HOME 时不按 HOME；按 Y 一直按到关闭软件的确认框出现；之后按了两次 A。
- `restart_to_title`：选用户的界面一直不出现时抛 `TimeoutError`。
- `enter_game`：画面一开始就是黑的，一次 A 都不按；第 3 张图变黑，按了 2 次 A。

## 实现

不能改 `tests/`。

1. 按「文件对照」用 `git mv` 移动。`menu_last_item.py` 和 `move_menu_option.py` 合并时，两个函数原样放进 `flow/menu.py`，import 去重。
2. 新建 `src/control_switch/flow/__init__.py`、`src/control_switch/device/__init__.py`。
3. 删掉 `src/tools/` 整个目录，删掉 `src/libs/__init__.py` 里对 `Switch` 的导出（文件留着，`xoroshiro.py` 还在这个目录）。
4. 全项目按「引用的写法」改 import，包括 `src/main.py`、`src/restart.py`、`src/sv/`、`src/swsh/`。
5. `scripts/find_switch.py`：改根目录的计算。`Makefile` 的 `find` 命令、`README.md` 和 `.env.example` 里提到 `src/tools/find_switch.py` 的地方改成新路径。
6. 跑 `make typecheck`，把搬进来的文件里的报错清掉。为了消除 pyright 报错可以补类型标注、加必要的判空，但不能改变运行时的行为。
7. 除了 import、上面这几处路径和上一条，不改任何代码。
