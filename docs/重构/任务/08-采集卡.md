# 任务 08：采集卡

## 目标

取图可以用采集卡：`SCREEN=capture` 时，从采集卡取 Switch 底座输出的画面。这样没破解的那台 Switch 也能取图。画面原样用 1920×1080，不缩小。按键、内存这次不动。

取图、按键都不用 botbase 并且 `MEMORY=none` 时，不去连 botbase。

## 开始前的状态

- `device/base.py` 有 `Screen` 接口：`pixel_peek() -> bytes`（返回 JPEG 字节）、`close()`。
- `device/botbase.py` 的 `Botbase.pixel_peek` 返回 botbase 截的 JPEG。`vision` 里的坐标范围都按占画面宽高的比例写，1920×1080 和 1280×720 都能用（`docs/实测-分辨率定位.md`）。
- `settings.py` 的 `screen` 可以写 `botbase`、`capture`；`device/factory.py` 遇到 `capture` 抛 `NotImplementedError`。
- `device/factory.py` 先打开单片机（`CONTROLLER=serial` 时）再连 botbase，连 botbase 失败时先关掉单片机；现在一定会连 botbase。
- `device/check.py` 有 `DeviceCheckError`；`check_devices` 检查取图：取得到、能解码、是 16:9，全黑时记警告。
- 依赖里已经有 `opencv-python-headless`（5.0.0.93），headless 版也能用 AVFoundation 打开采集卡（实测用的就是项目的环境）。
- 上一个任务的改动已经提交。工作区里只允许有这几项和本任务无关的改动：`data/swsh/lair_event_LUT.json`、`docs/计划-盾剑本地联机对战.md`、`docs/重构/总览.md`、这个任务文件。还有别的改动时先停下来问，不要开始。

## 硬件（2026-11-24 实测）

- 采集卡：绿联 UGREEN HDMI Capture，USB 3.0，MS2130 芯片，Mac 上免驱，系统里是摄像头设备。Switch 要插在底座上才有画面输出。
- OpenCV 用 `cv2.VideoCapture(序号, cv2.CAP_AVFOUNDATION)` 打开。这台 Mac 上 0 号是采集卡（1920×1080），1 号是 OBS 虚拟摄像头（1920×1080），2 号是 FaceTime 摄像头（1280×720）。序号由系统排，插拔设备后可能会变。
- 打开时设 `CAP_PROP_FRAME_WIDTH=1920`、`CAP_PROP_FRAME_HEIGHT=1080`，拿到的是 1920×1080。打开到读出第一帧约 0.11 秒。
- 连续 `read()` 每帧约 16 ms（60 帧）。空闲 2 秒后的第一次 `read()` 只要 7 ms，但用单片机按 HOME 之后马上读，第一帧就是新画面（0.14 秒内画面变化），不用先扔掉缓冲里的旧帧。
- 1920×1080 编码成 JPEG（`cv2.imencode(".jpg", …)`，默认质量）约 8 ms，150 KB 左右。
- 终端要有摄像头权限（系统设置 → 隐私与安全性 → 摄像头）。没有权限时 `read()` 读不到画面。

## 约定

### `settings.py`

| 字段 | 环境变量 | 不写时 | 说明 |
|---|---|---|---|
| `capture_device` | `CAPTURE_DEVICE` | `0` | 采集卡在 OpenCV 里的序号，整数；不是整数或者是负数时抛 `ValueError`，报错里有 `CAPTURE_DEVICE` |

空字符串当作没写，和其他几项一样。

### `device/capture_card.py`

- 类 `CaptureCard`，实现 `Screen`。`device` 外面不引用它。
- 构造：`CaptureCard(video: VideoSource)`。`VideoSource` 是同一个文件里的 `typing.Protocol`，只要 `read() -> tuple[bool, 图片或 None]`、`release() -> None`。`cv2.VideoCapture` 符合它，测试里的假采集卡也符合它。
- 函数 `open_capture_card(settings) -> CaptureCard`：
  1. 用 `cv2.VideoCapture(settings.capture_device, cv2.CAP_AVFOUNDATION)` 打开，设宽 1920、高 1080。
  2. `isOpened()` 是 `False`：抛 `DeviceCheckError`，报错是 `取图：采集卡打不开（CAPTURE_DEVICE={序号}），检查采集卡有没有插好、序号对不对`。
  3. 读一帧，读不到（`ok` 是 `False` 或者图片是 `None`）：释放设备，抛 `DeviceCheckError`，报错是 `取图：采集卡打开了但读不到画面（CAPTURE_DEVICE={序号}），检查终端有没有摄像头权限`。
  4. 读到的画面不是 1920×1080：记一条警告，写出实际大小，照样返回。可能序号指到了别的摄像头。
- `capture_card.py` 用 `import cv2`，测试里替换 `control_switch.device.capture_card.cv2.VideoCapture`。
- `pixel_peek()`：`read()` 一帧，用 `cv2.imencode(".jpg", 图片)` 编码，返回字节。不缩小、不裁剪。读不到时再读一次，连续 3 次读不到抛 `ConnectionError`，报错是 `取图：采集卡读不到画面`。编码失败抛 `ConnectionError`。
- `close()`：`release()`；调用多次只释放一次，不出错。

### `device/factory.py`

- `screen` 是 `capture` 时调 `open_capture_card(settings)`，不再抛 `NotImplementedError`。`factory.py` 用 `from .capture_card import open_capture_card` 引用；测试里替换 `control_switch.device.factory.open_capture_card`。
- 打开顺序：采集卡 → 单片机 → botbase。后面的打开失败时，先把前面已经打开的关掉，再抛错。
- 取图、按键、内存三项都不用 botbase 时（`SCREEN=capture`、`CONTROLLER=serial`、`MEMORY=none`），不连 botbase。
- 用到 botbase 的几项照旧共用一个连接，只连一次。

### `device/check.py`

- 不改。采集卡取到的图照样走 `_check_screen`：能解码、是 16:9，全黑记警告。
