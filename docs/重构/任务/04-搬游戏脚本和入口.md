# 任务 04：搬游戏脚本和入口

## 目标

把两个游戏的代码和入口搬进 `control_switch` 包，运行方式改成命令 `control-switch`。做完后 `src/` 下只剩 `control_switch` 一个目录。只移动文件、改 import、改入口，游戏逻辑一行不动。

## 开始前的状态

- `control_switch` 里已经有 `types`、`config`、`notifier`、`pkhex`、`log`、`vision`、`flow`、`device/botbase.py`。
- 还在外面的：
  - `src/sv/`、`src/swsh/`：两个游戏的代码
  - `src/libs/xoroshiro.py`：只有 `src/swsh/lair/lair.py` 在用
  - `src/main.py`：跑脚本的入口
  - `src/restart.py`：重启游戏的入口
  - `src/scripts.py`：脚本表，`SCRIPTS` 和 `load_script`
- `Makefile` 用 `uv run python src/main.py $(script)` 和 `uv run python src/restart.py $(script)` 运行。

## 约定

文件对照：

| 原来 | 搬到 |
|---|---|
| `src/sv/` | `src/control_switch/games/sv/` |
| `src/swsh/` | `src/control_switch/games/swsh/` |
| `src/libs/xoroshiro.py` | `src/control_switch/games/swsh/lair/xoroshiro.py` |
| `src/scripts.py` | `src/control_switch/games/registry.py` |
| `src/main.py` 和 `src/restart.py` | 合并成 `src/control_switch/__main__.py` |

引用的写法：

| 原来 | 改成 |
|---|---|
| `from sv... import`、`from swsh... import` | `from control_switch.games.sv... import`、`from control_switch.games.swsh... import` |
| `from libs.xoroshiro import Xoroshiro` | `from .xoroshiro import Xoroshiro` |
| `from scripts import load_script` | `from control_switch.games.registry import load_script` |

命令行：

- `control-switch run <脚本>`：原来 `main.py` 做的事。
- `control-switch restart <脚本>`：原来 `restart.py` 做的事。
- `<脚本>` 不写时是 `swsh/lair`。
- `__main__.py` 里有一个 `main(argv: list[str] | None = None)`，`argv` 不传时用命令行参数。`python -m control_switch` 和 `control-switch` 都走它。
- 日志目录的名字不变：`run` 用 `"start"`，`restart` 用 `"restart"`。
- `registry.py` 里 `SCRIPTS` 的名字不变（`swsh/lair`、`sv/outbreak`），对应的模块改成 `control_switch.games.swsh.lair`、`control_switch.games.sv.outbreak`。

## 写测试

只能改 `tests/`。期望值用搬之前的代码跑出来的结果（设置 `PYTHONPATH=src` 后引用 `swsh...`、`libs.xoroshiro`），不要自己推算。

   - `Xoroshiro`：固定种子连着取几个数，写成期望值。

   - `main(["run", "没有/这个"])` 抛 `SystemExit`。

不要写任何会真的去连 Switch 的测试。

## 实现

不能改 `tests/`。

1. 按「文件对照」用 `git mv` 移动，新建 `src/control_switch/games/__init__.py`。
2. 删掉 `src/libs/`、`src/main.py`、`src/restart.py`、`src/scripts.py`。
3. 写 `src/control_switch/__main__.py`：两个命令的做法照搬原来两个文件，`load_dotenv()` 放在 `main` 里最前面。
4. 全项目按「引用的写法」改 import。
5. `pyproject.toml` 加 `[project.scripts]`：`control-switch = "control_switch.__main__:main"`，然后 `uv sync`。
6. `Makefile`：`start` 改成 `uv run control-switch run $(script)`，`restart` 改成 `uv run control-switch restart $(script)`。
7. `README.md` 里的目录说明和运行方式跟着改。
8. 跑 `make typecheck`，把搬进来的文件里的报错清掉。为了消除 pyright 报错可以补类型标注、加必要的判空，但不能改变运行时的行为。
9. 除了 import、入口和上一条，不改任何代码。

3. `make typecheck` 0 报错。

8. `uv run python -m control_switch run 没有/这个` 结果一样。
