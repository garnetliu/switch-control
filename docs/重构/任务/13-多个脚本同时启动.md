# 任务 13：多个脚本同时启动

设计还没定，这里先记下要做什么和现在的限制，定了再补「约定」「写测试」「实现」「测试」。

## 目标

多个脚本可以同时启动，各跑各的。

## 现在为什么只能跑一个

- `make start script=…` 和 `control-switch run <游戏/脚本>` 一次只跑一个脚本（`src/control_switch/__main__.py` 的 `run`）。
- 设备配置只有一套：`.env` 里只有一组 `SCREEN`、`CONTROLLER`、`MEMORY`、`SWITCH_CONNECTION`、`SWITCH_IP`、`SERIAL_PORT`、`CAPTURE_DEVICE`，所有脚本共用。
- 极巨大冒险的运行状态写在固定的 `run/game.yaml`（`games/swsh/lair/game_config.py:310` 的 `game_state_file`），同一个脚本开两个会互相覆盖。
- 日志按脚本分目录（`logs/swsh-lair/`、`logs/sv-outbreak/`、`logs/sv-egg/`），同一个脚本开两个会写进同一个目录。

## 要定的

- 每个脚本用哪一套设备、哪台 Switch，配置写在哪里。
- 怎么启动：一条命令启动几个，还是分开启动几个进程。
- 同一个脚本能不能同时开几个。能的话，运行状态和日志怎么分开。
- 停止、重启、出错通知怎么对应到具体哪一个。
