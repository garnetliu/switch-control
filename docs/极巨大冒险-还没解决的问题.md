# 极巨大冒险：还没解决的问题

2026-11-18 晚整理。数据和推导过程见 [实测-打分算法对比.md](实测-打分算法对比.md)，脚本在 `打分算法探索脚本/`。

## 一、打分算法本身

| 问题 | 现状 |
|---|---|
| 首领「能一回合打死」的门槛是断崖 | 四只进攻合计刚过 2.3（`boss_kill_attack`）和差一点的，首领分差四五倍。seed 16753139388389203475 合计 2.31 算成一回合，实测两回合、9.2 到 10.3 分钟。依据只有 9004205710319247536 和 6986731677711377285 两张图 |
| 队友的伤害估不准 | 现在按四个招式平均算。实测队友会出愤怒粉、日光束这类，不是「要么出最强的，要么出变化招式」。战斗文字日志（「战斗文字:」）在攒，还没用来统计队友的出招规律 |
| 回合数预测只对六成 | 没算速度线（谁先出手）、命中率、对手的守住和挺住。去掉队友带变化招式的场、自己满命中的 16 场能对 88% |
| 极巨化血量翻倍没算 | 只算了进攻变没变 |
| 新算法选的方案大多没实测 | 日志里出现过的 111 张图，版本 10 选的首发加路线和版本 9 完全一样的只有 29 张 |
| 背包客和树果没算进分数 | 只记进了事件表 |

## 二、seed 抽数规则里还没推完的

已经推出来的规则见「队友换不换、研究员给什么，都是 seed 定死的」一节。

| 问题 | 现状 |
|---|---|
| 抓超梦之后第 3 只给谁对得差 | 路上没有事件的局里 5 个只对 1 个，还有一处没找到 |
| 每抓一只开头那个 0～2 的数管什么 | 不知道，只知道它占位置（抽到 3 重抽） |
| 整体还有两成对不上 | 抓到的给谁对 80%，研究员给哪只对 22/36。「队友先换上抓到的、紧接着又被研究员换掉」日志里看不到中间那步，会被判成错 |
| 背包客那一组还没用实际数据确认 | 推出来的是三个队友各抽一个 0～4（拿第几样道具）。「队伍道具:」日志 11-18 19:35 才加上，等遇到背包客之后对：抽到的数是不是等于实际拿的位置 |
| 30 种布局的事件表不全 | `src/control_switch/games/swsh/data/lair_event_LUT.json` 只有走过的位置。整张地图只看过 3x2 布局 0 一张（右摇杆往上推，镜头能一直移到首领）。岔路口存的图只有当前位置附近一小块 |
| 研究员之前用掉几个随机数 | 同一种布局、同一个位置基本固定（差 0 到 1 个）。按上面的规则连着算能对上一部分，没走过的岔路上有什么还不知道 |
| 开头第一次抽数抽的是什么 | 已经清楚：在没抓到的神兽里按遭遇表的顺序挑一只，上限 = 没抓到的只数 − 1（11-19 选不指定打了两局验证：艾姆利多、卡璞・蝶蝶）。能遇到的是 29 只：奈克洛兹玛和究极异兽一起解锁，这个存档没解锁 |
| 抽对手时双属性多用的那个随机数管什么 | 猜是地图节点上显示哪个属性的标签，没验证 |

社区和 GitHub 上没有找到这些规则：pokeldn（我们的 seed 算法参照的项目）明确写着路上遇到什么是 unknown；PKHeX 不涉及；攻略站只说研究员给随机的租借宝可梦。

## 三、推出来了但还没接进代码

`plan.py` 和 `find_lair_seed.py` 现在还是：

- 自己不换的那只按「1/8 没人换，其余平均分给三个队友」取期望。实际每张图是定死的，能从 seed 直接算。
- 路线上有研究员就把一个队友换成 `plan.AVERAGE`（全部租借的平均），换哪个队友按三个机会一样。实际给哪只、换掉谁也能算。
- 背包客不占随机数。实际占 3 到 10 个，不算的话背包客之后的全错位。

接进去需要：整条路线上每个位置的事件（事件表不全的位置只能当没有）、首领是不是双属性。找 seed 的批量版要跟着改。

## 四、程序和数据

| 抓到神兽后要改抽数上限 | 已解决（11-19）：每局开头从存档读每只神兽「抓过没有」的开关和「究极异兽解锁了没有」（`LairSwitch.caught_legends`），上限自动算；读不出来时用配置里的 `lair_caught`。选「不指定」（配置 `boss = None`）时首领也从 seed 算（`Lair.boss`），实测对过艾姆利多和卡璞・蝶蝶两局 |
