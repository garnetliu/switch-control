# 计划：盾和剑本地联机对战，全部由 Mac 控制

2026-11-23 定。破解机在 emuMMC 里开盾，没破解的机器开剑，两台本地联机对战，取图、按键都由 Mac 控制。

已经打通的（11-21 的记录、`docs/重构/记录/09.md` 的实测）：单片机串口 9600，握手、按键都回 `FF`；采集卡是绿联，OpenCV 第 0 号设备，1920×1080。采集卡在代码里还没接（任务 08 没做）。

## 一、硬件和游戏准备（人来做）

1. **破解机（A，盾）**
   - 用 hekate 进 emuMMC，在 emuMMC 里装好盾。
   - 确认 emuMMC 屏蔽了任天堂服务器。本地通信不走服务器，屏蔽不影响联机。
   - usb-botbase 装在 SD 卡的 `atmosphere/contents` 里，真实系统和 emuMMC 共用，不用另装。
   - A 用 USB 线直连 Mac，取图、按键、内存都走 botbase。
2. **没破解的机器（B，剑）**
   - 插底座，单片机的 USB 插底座，底座 HDMI 接采集卡，采集卡接 Mac。
   - TTL 接 Mac 和单片机，接法照旧。
3. **两边游戏版本要一样**
   - 本地联机要求版本相同。B 能联网更新到 1.3.2；A 在 emuMMC 里不能联网，要离线装 1.3.2 的更新。
   - 有没有 DLC 两边也最好一致。
4. **Mac 要 3 个 USB 口**：A 的 USB 线、采集卡（要 USB 3.0）、TTL。
5. **先手动打一场**：两台都开 Y 通信 → 对战 → 本地通信，设同一个连接密码，确认能连上、能打完。再用 Mac 的屏幕共享看采集卡画面，确认 B 有画面。

## 二、补完重构（三个角色）

6. **任务 08 采集卡**
   - 先写任务文件，要实测：
     - 1080p 帧要不要缩到 720p。现在的坐标都按比例算，但模板匹配和一些像素阈值是按 1280×720 定的。
     - 读一帧的耗时。
     - Switch 不在底座上时是不是全黑。
   - 实现 `device/capture_card.py` 和 `SCREEN=capture`。
   - 补上任务 09 留下的「三项都不用 botbase 时不连 botbase」。
7. **任务 10 交叉组合验证和 `check` 命令**
   - A 用组合 1（三项都 botbase），B 用组合 8（采集卡、单片机、无内存），两种都要真机跑通 `make check`。
8. **能同时跑两套设备**
   - 现在一个进程只读一份 `.env`。
   - 加一个命令行参数 `--env <文件>`，比如 `.env.shield` 和 `.env.sword`。
   - 两个进程各管一台，日志目录按配置分开，不互相覆盖。

## 三、联机对战脚本（新写）

9. **截图校准**：两台各截一套联机流程和对战界面的图，放进 `logs/keep/`，B 的图从采集卡来：
   - Y 通信菜单
   - 本地通信
   - 连接密码输入
   - 等对手
   - 选队伍
   - 对战中选招式、选目标
   - 胜负结算
10. **新脚本 `swsh/link_battle`**
    - 声明 `REQUIRES = {"screen", "controller"}`，不要内存，B 没有内存也能跑。
    - 步骤：
      1. 打开 Y 通信 → 对战 → 本地通信。
      2. 输入固定的连接密码。
      3. 等对手。
      4. 选队伍。
      5. 对战循环：轮到自己就选招式。
      6. 结算后回到原地，接着下一场。
    - 选招式先用最简单的规则，比如固定第 1 招，跑通了再接打分。
    - 菜单、光标、等画面复用 `flow/` 里的 `wait_for`、`press_until`、`menu`。
    - 极巨大冒险对战的识别不能直接拿来用，界面不一样。
11. **两台怎么配合**
    - 两个进程各自看自己的画面，不互相通信，双方等对手这一步由游戏自己同步。
    - 唯一要约好的是连接密码和开始时机，写进两份配置就行。
    - 哪天要按回合配合，再改成一个进程管两个 `Session`。
12. **盾这边可选读内存**：比如读对手是哪只、读回合，用来选招式，也可以拿来对照 B 画面识别得对不对。

## 四、验证

13. 两台各跑 `make check` 通过。
14. 两个终端分别 `control-switch run --env .env.shield swsh/link_battle` 和 `--env .env.sword`，连打 10 场：
    - 不卡住。
    - 每场有胜负记录。
    - 出错时截图写进各自的日志目录。
15. 故意出错各试一次，看报错能不能看懂：
    - 拔采集卡。
    - 拔 TTL。
    - 一边先开、另一边晚 1 分钟。

## 开始前

A 在跑极巨大冒险刷闪，用的是真实系统。改 emuMMC 和后面实测都要用 A，开始前先停刷闪，在一局打完、下一局开头时停。
