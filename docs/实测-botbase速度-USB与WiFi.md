# 实测：botbase 的读写内存、截图、按键速度（USB 与 Wi-Fi）

测试脚本：`docs/实测脚本/botbase速度.py`（`PYTHONPATH=src uv run python docs/实测脚本/botbase速度.py usb|wifi`）。

测试条件：剑盾停在极巨大冒险的大厅里。读、写的位置都是道具口袋（heap `0x45067A98 + 0x2F8`）；
写内存是把原来的内容原样写回去，写完再核对一遍。每一项测 20 次（按键测 10 次），下面写的都是中位数。

## USB（usb-botbase，Switch 直连 Mac，2026-11-21）

| 操作 | 大小 | 用时（中位） | 最快 / 最慢 |
|---|---|---|---|
| 读内存 peek | 4 B | 53.3 ms | 3.3 / 55.2 ms |
| | 0x158 B（一只宝可梦） | 53.6 ms | 53.0 / 55.4 ms |
| | 4 KB | 54.2 ms | 52.9 / 57.1 ms |
| | 16 KB | 54.3 ms | 53.5 / 56.2 ms |
| | 64 KB | 56.1 ms（约 1.1 MB/s） | 54.9 / 57.0 ms |
| 写内存 poke（发出去为止） | 4 B | 52.8 ms | 49.4 / 54.2 ms |
| | 0x158 B | 52.9 ms | 51.4 / 54.7 ms |
| | 1 KB | 53.0 ms | 51.0 / 55.0 ms |
| 写内存 + 读 4 B 确认 | 4 B / 0x158 B / 1 KB | 106–107 ms | 105.6 / 109.2 ms |
| 截图 pixelPeek | 1280×720 JPEG 约 190 KB | 100.0 ms | 95.5 / 109.4 ms |
| 按键 click X：命令发出去 | | 33.8 ms | 0.6 / 39.7 ms |
| 按键 click X：发出到截图里看到菜单 | | 527.8 ms | 417.9 / 534.6 ms |

- 读内存从 4 B 到 64 KB 用时几乎一样，都在 53–56 ms，大小基本不影响。
- 一次写内存发出去也是约 53 ms；写完马上读一次确认，合计约 106 ms，等于两条命令的时间相加。
- 一次写 0x898 字节（命令转成十六进制约 4.4 KB）会 USB Pipe error，随后 usb-botbase 断开、过了一会儿重新出现。
  游戏没受影响（道具口袋 170 种道具、极矿石 999 都在）。所以 USB 上一次写入不要超过 1 KB。
- 按键反应的测量精度受截图限制：截一张要 100 ms，看到变化前一般截了 4 张。
  所以「527.8 ms」里包含 click 本身按下、松开的时间、游戏打开菜单的时间，以及最多约 100 ms 的截图误差。
